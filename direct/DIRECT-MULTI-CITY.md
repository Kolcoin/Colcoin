## Как загрузить XLSX в Direct — 3 способа

### Способ 1 (рекомендуется): через интерфейс Direct

1. Заходишь на [direct.yandex.ru](https://direct.yandex.ru/)
2. Слева → **«Инструменты»** → **«Управление кампаниями с помощью XLS и XLSX»**
3. Вкладка **«Загрузка»**
4. **Кампания** → оставь «Создать новую кампанию» или выбери существующую
5. **Файл** → выбери `campaign_dolgoprudnyj.xlsx` (или другой)
6. Нажми **«Проверить»** — Direct проанализирует файл, покажет что найдено
7. Если ошибок нет → **«Импортировать»**
8. Направить на модерацию

**Сроки**: импорт занимает 1-3 минуты, модерация 1-3 дня.

### Способ 2: через Direct Commander (если первый не сработает)

[Direct Commander](https://yandex.ru/support/direct-commander/) — десктопное приложение Яндекса. Скачай, авторизуйся под своим аккаунтом → File → Import → XLSX → выбери файл.

Commander более гибкий — он сам подбирает колонки и не такой капризный к формату.

### Способ 3 (резервный): по Markdown summary вручную

Если ни XLSX-импорт, ни Direct Commander не подошли — открой соответствующий `campaign_{city}_summary.md` (Notion-friendly markdown с готовой структурой):

1. Создай новую кампанию в Direct (как для Мытищ — см. `DIRECT-MYTISHCHI.md`)
2. По очереди создай 4 группы
3. В каждую вставь ключи и тексты объявлений из markdown — копирование текстов идёт быстро

Один город таким способом займёт ~30 минут.

## Прогноз

При правильной настройке каждый новый город даст:
- **5-15 заявок в первый месяц** (когда Direct обучится)
- **20-40 заявок в стабильный месяц**

Конверсия в реальные заказы в ритуальной нише — 30-40%. То есть:
- 4 новых города × 20-30 заявок = **80-120 заявок/мес**
- × 30% конверсия = **25-35 заказов/мес**
- × 70-90 тыс ₽ средний чек = **1.75-3 млн ₽ выручки/мес**

При расходе **88-100 тыс ₽/мес на Direct** во всех 4 городах — ROI 20-30x.

## Если что-то пошло не так при загрузке

| Проблема | Решение |
|---|---|
| Direct пишет «Файл не соответствует шаблону» | Сначала **выгрузи** пустой шаблон из своего аккаунта Direct (вкладка «Выгрузка»), открой его, и скопируй данные из моего XLSX в правильные колонки |
| Импортировались не все группы | Попробуй Direct Commander (Способ 2) или ручное создание |
| Ключи импортировались, но без минус-фраз | Минус-фразы есть только в первой строке кампании — Direct может это не распознать. Скопируй минус-фразы из `campaign_{city}_summary.md` в раздел «Минус-фразы кампании» вручную |
| Быстрые ссылки не появились | То же — добавь вручную через «Дополнительные элементы → Быстрые ссылки» |
