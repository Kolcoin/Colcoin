# Бот «Вынос мусора» (MVP)

Минимальный Telegram-бот на aiogram 3.x. Три роли:
- **Клиент** — заказывает вынос мусора
- **Курьер** — принимает заявки, отправляет фото-отчёт
- **Админ** — получает копию всех заявок и фото

Цена: первый пакет 150₽, каждый следующий +60₽. (1→150, 2→210, 3→270.)

## Что нужно перед запуском

1. **Токен бота**. Создай бота у [@BotFather](https://t.me/BotFather), команда `/newbot`. Скопируй токен вида `1234567890:ABCdef...`
2. **Свой Telegram ID** (админа). Напиши боту [@userinfobot](https://t.me/userinfobot), он покажет твой `id`.
3. **Telegram ID курьера**. Попроси курьера написать тому же `@userinfobot` и прислать тебе число.

## Установка и запуск (локально)

```bash
cd garbage-bot
python3 -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env
# открой .env и впиши BOT_TOKEN, ADMIN_ID, COURIER_ID
python bot.py
```

Дальше с телефона: пиши боту `/start` → жми «🗑 Вынести мусор» → проверь, что у курьера/админа приходят сообщения.

## Размещение на Beget

Beget поддерживает «Хостинг ботов» (Python 3.x) — это самый простой вариант:

1. В панели Beget → раздел **Боты Telegram** → создай нового бота
2. Загрузи **ZIP** проекта (см. ниже) или клонируй из Git
3. В разделе **Переменные окружения** впиши `BOT_TOKEN`, `ADMIN_ID`, `COURIER_ID`
4. Укажи команду запуска: `python bot.py` (или то, что предложит панель)
5. Включи бота

Альтернатива — VPS на Beget: ставишь Python, virtualenv, запускаешь через `systemd` или `screen`.

```
├── bot.py                 # точка входа

├── storage.py             # in-memory хранилище заявок
├── handlers/
│   ├── client.py          # сценарий клиента (FSM)
│   └── courier.py         # сценарий курьера (приём + фото)

├── requirements.txt
└── README.md
```

## Команды

- `/start` — клиенту показывает меню
- Кнопка «🗑 Вынести мусор» — запускает заявку
- Курьеру: кнопка «✅ Принять заказ #N» под каждой заявкой, потом фото-сообщение
