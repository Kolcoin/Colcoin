# Monuments pack (17 models)

This folder contains legal similar images and prices for models 1-1..1-17.

## Files
- `images/` — 17 SVG images (`model-1-1.svg` ... `model-1-17.svg`).
- `price_list_17_models.csv` — full size/mass/price rows for each model.
- `model_cards_17.csv` — one line per model with image and base price.
- `price_list_17_models.json` — JSON export of full table.
- `LICENSES.md` — source links and license for each image.

## Note
Price rows are transcribed from the user-provided photographed price sheets; verify before final publication.
