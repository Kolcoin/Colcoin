# Бот «Вынос мусора» для мессенджера МАКС

Полный аналог Telegram-версии, переписан под **MAX Bot API** (мессенджер от VK, max.ru).

Стек: `maxapi-sdk` 0.13.0 + `python-dotenv`.

## Что умеет

- **Клиент** оформляет заказ за 5 шагов: день → время → пакеты → адрес → телефон
- Бот считает цену по правилу: 1→150₽, 2→210₽, 3→270₽, 4→330₽
- Клиент оплачивает по внешней ссылке (ЮKassa / СБП), жмёт «✅ Я оплатил»
- Заказ падает в **группу курьеров** + копия админу в личку
- **Админ** в группе нажимает «Передать курьеру #N» → курьер получает заказ
- **Курьер** жмёт «Выполнено», шлёт фото → фото уходит клиенту и в группу

## ⚠️ Что НЕ так, как в Telegram-версии

| Telegram | MAX |
|---|---|
| Встроенные платежи `send_invoice` + `provider_token` + `pre_checkout_query` | **Нет в MAX Bot API.** Используем внешнюю ссылку + ручную кнопку «Я оплатил» |
| `chat.id = -100...` для групп | Другой формат chat_id (узнаётся через `/id` в группе) |
| Один токен подходит и для Telegram | Нужен **новый токен** с https://business.max.ru |

## Перед запуском (что нужно получить)

1. **Токен MAX-бота** — заходишь на [business.max.ru](https://business.max.ru), создаёшь бота, копируешь токен
2. **MAX-ID админа и курьера** — узнаются командой `/id` боту (после первого запуска)
3. **chat_id группы курьеров** — создай группу в MAX, добавь бота, напиши в группе `/id` — бот ответит
4. **Платёжная ссылка** — создаёшь в [ЮKassa](https://yookassa.ru) или СБП-кошельке универсальную ссылку. Например, https://yoomoney.ru/quickpay/...
5. **Username саппорта** — твой ник в MAX (без `@`)

## Установка и запуск (локально)

```bash
cd max-bot
python3 -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env
# открой .env и впиши значения
python bot.py
```

### Первый запуск — узнать ID

При первом запуске у тебя ещё нет `ADMIN_ID`, `COURIER_ID`, `GROUP_ID`. Сделай так:

1. Впиши только `MAX_BOT_TOKEN` и `PAY_LINK`. Остальные временно поставь нулями.
2. Запусти бот: `python bot.py`.
3. Напиши боту в личку команду `/id` → бот пришлёт твой `user_id` и `chat_id`. Это твой `ADMIN_ID`.
4. Попроси курьера написать боту `/id` → курьер пришлёт тебе число. Это `COURIER_ID`.
5. Создай группу в MAX, добавь туда бота, напиши в группе `/id` → бот ответит `chat_id` группы. Это `GROUP_ID`.
6. Запиши все три значения в `.env`, перезапусти бот.

## Размещение на Beget

В целом так же, как для Telegram-версии (см. `garbage-bot/README.md`). Загружаешь ZIP-архив (`max-bot.zip` из артефактов), вписываешь переменные окружения в панели, команда запуска `python bot.py`.

⚠️ **Если у Beget «Хостинг ботов» поддерживает только Telegram-токены**, размещай на VPS или Cloud Apps от Beget — там просто Python и сделать `systemd`-юнит.
