# Городской Ритуал — Химки

Одностраничный сайт-визитка ритуального агентства **«Городской Ритуал»**
(юр. лицо — ООО «Урбан Брокер»), работающего в городе Химки и Химкинском округе.

Сайт реализован как статический лендинг (HTML + CSS + минимум JS) — без сборщиков
и без бэкенда. Открывается локально двойным кликом по `index.html` или с любого
веб-сервера.

## Структура

```
.
├── index.html              # разметка лендинга
├── styles.css              # стили (палитра, типографика, адаптив)
├── script.js               # маска телефона + отправка формы (заглушка)
└── assets/
    └── products/
        ├── coffin_kosichka_6_oreh.jpg
        ├── coffin_ekol_4_oreh.jpeg
        └── wreath_elite_30.jpg
```

## Источник изображений

В `assets/products/` лежат три изображения товаров, скачанные по ссылкам,
присланным заказчиком, с сайта `фаворит-ритуал.рф`:

- `coffin_kosichka_6_oreh.jpg` — модель «Косичка», 6-гранный, орех (ФКО-6);
- `coffin_ekol_4_oreh.jpeg` — модель «Эколь», 4-гранный, орех (Ф-5);
- `wreath_elite_30.jpg` — венок «Элит №30» производства «Ратин».

**Важно:** перед запуском сайта в продакшен эти изображения необходимо
заменить на собственные фотографии товаров либо получить письменное
разрешение правообладателя на их использование.

## Деплой

Сайт — статический, его можно положить на любой хостинг:

- **GitHub Pages / Netlify / Vercel / Cloudflare Pages** — drag-and-drop корня репозитория.
- **Nginx / Apache** — скопируйте файлы в `/var/www/...`, корень — `index.html`.
- **Beget / Timeweb / reg.ru** — загрузите файлы по FTP в `public_html/`.

Для подключения формы обратного звонка к CRM/Telegram дополните функцию
`submitCallback` в `script.js`.

## Локальная проверка

```bash
python3 -m http.server 8000
# затем откройте http://localhost:8000
```
