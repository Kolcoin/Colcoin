## 1. Лендинг брокера / агентства недвижимости

```
Создай одностраничный лендинг для брокера по новостройкам.

Технологии: чистый HTML5 + CSS3 (CSS custom properties, grid, clamp()) + vanilla JavaScript ES6+. Без фреймворков, без сборки, без зависимостей. Единственный внешний ресурс — Google Fonts (Inter).

Структура (каждый блок — отдельная <section>):
1. Sticky header с навигацией и кнопкой «Оставить заявку»
2. Hero-секция: заголовок H1 с ключевой фразой, подзаголовок, 4 KPI-карточки (комиссия, скорость подборки, кол-во статей, рейтинг), CTA-кнопка, форма заявки (имя + телефон) в боковой карточке
3. Каталог рекомендуемых проектов — карточки из JS-массива с title, district, metro, price, sourceUrl
4. Блок стартов продаж, разделённый по пользовательским сценариям (первая квартира / инвестиция / расширение). Каждый сценарий — отдельный блок с иконкой-эмодзи, описанием, тегами и вложенными project-card
5. Блок SEO-статей с квадратной карточкой (aspect-ratio: 1/1), изображением, описанием и ссылкой на детальную страницу
6. Сегментация по цели покупки — goal-блоки
7. Пошаговый процесс (4 шага): от заявки до сделки
8. Проекты с повышенным спросом — карточки
9. Локации и районы — district-card
10. Блок «Почему выбирают нас» — тёмная секция с features и stats
11. FAQ — faq-card с вопросами
12. CTA-секция с gradient-фоном + сетка контактных карточек (телефон, Telegram, YouTube, Instagram)
13. Footer с контактами в виде вертикального списка

JavaScript:
- Все данные (проекты, районы, лид-форма) хранятся в JS-массивах в начале файла
- Рендер через innerHTML из шаблонных строк
- Форма при нажатии кнопки показывает alert с персонализацией по имени
- Функции: renderCards(), renderDistricts(), renderLaunchBlocks(), setupLeadForm()

CSS:
- CSS custom properties в :root для всех цветов, радиусов, теней
- Адаптив: @media 1024px (планшет), @media 680px (мобильный)
- Класс-система: .btn, .btn-large, .btn-outline, .btn-warm, .btn-cool, .btn-berry
- Grid-система: .cards-grid с 4 колонками → 2 → 1

SEO:
- Полный набор meta (description, keywords, robots, og:*, twitter:*)
- JSON-LD: WebSite, Organization, LocalBusiness, RealEstateAgent, BreadcrumbList, FAQPage, ItemList
- Canonical URL, hreflang, geo-мета

Стиль: минималистичный, профессиональный, белый фон + фиолетовый accent (#5c4dff). Все тексты — на русском языке.
```

## 2. Персональный лендинг эксперта / консультанта

```
Создай персональный лендинг для эксперта-консультанта.

Технологии: один файл HTML + встроенный CSS + встроенный JS. Никаких зависимостей кроме Google Fonts (шрифт на выбор: Manrope или Inter).

Структура:
1. Hero на весь экран: фото-заглушка (CSS gradient вместо фото), имя, должность, 1-строчный слоган, 2 кнопки (Записаться на консультацию / Скачать гайд)
2. Секция «Обо мне» — 2 колонки: текст + список фактов (лет опыта, клиентов, публикаций)
3. Секция «Услуги» — 3 карточки с иконками-эмодзи, названием, описанием и ценой
4. Секция «Кейсы» — горизонтальный скролл карточек с результатом (до → после, метрики)
5. Секция «Отзывы» — карусель (JS): 3 отзыва с именем, фото-заглушкой, текстом и компанией. Автоматическая прокрутка каждые 5 секунд + стрелки
6. Секция «Публикации» — 3 карточки статей со ссылками
7. CTA-блок с формой записи (имя, email, тема запроса — select с опциями)
8. Footer: соцсети (ссылки), копирайт

JS:
- Карусель отзывов с Intersection Observer для авто-паузы вне экрана
- Smooth scroll для якорных ссылок
- Форма: валидация email через regex, показ success-сообщения

CSS:
- Градиентный hero (linear-gradient 135deg)
- Hover-анимации на карточках (transform + box-shadow transition)
- Scroll-snap для секции кейсов
- Тёмная/светлая палитра через CSS variables
- Полная адаптивность: 3 breakpoint (1200, 768, 480)

SEO: meta description, og:title, og:description, og:image (placeholder), JSON-LD Person + ProfessionalService.

Язык контента: русский. Тематика: финансовый консультант (можно легко заменить нишу).
```

## 3. Лендинг SaaS-продукта

```
Создай лендинг для SaaS-продукта (сервис аналитики / CRM / таск-менеджер).

Технологии: HTML + CSS + vanilla JS. Без фреймворков. Google Fonts (Inter или Plus Jakarta Sans).

Структура:
1. Header: логотип (текст + SVG-точка), навигация (Возможности, Тарифы, Клиенты, Блог), кнопка «Попробовать бесплатно»
2. Hero: крупный H1 (60px+), подзаголовок, 2 кнопки (Начать бесплатно + Смотреть демо), анимированный mockup (CSS-only: скруглённый прямоугольник с фейковым UI из div-ов, пульсирующие точки)
3. Логотипы клиентов: горизонтальная лента из 6 серых SVG-лого (заглушки)
4. Возможности: 3 колонки × 2 ряда feature-карточек. Каждая: иконка (эмодзи или SVG), заголовок, описание
5. «Как это работает»: 3 шага с нумерацией, иконками и линией-коннектором между шагами (CSS ::after)
6. Тарифы: 3 колонки (Free / Pro / Enterprise). Выделенный «Pro» — увеличенный, с бейджем «Популярный». Каждый: цена/мес, список фич с галочками/крестиками, CTA
7. Отзывы: 3 карточки (цитата, имя, должность, компания)
8. FAQ: аккордеон на JS (клик раскрывает ответ, остальные закрываются)
9. CTA-секция: градиентный фон, крупный заголовок, поле email + кнопка «Начать»
10. Footer: 4 колонки (Продукт, Компания, Ресурсы, Контакты), копирайт

JS:
- FAQ-аккордеон
- Pricing toggle (месяц/год) с пересчётом цен
- Smooth scroll
- Intersection Observer для fade-in анимаций при скролле

CSS:
- Design tokens в :root: --color-primary, --color-surface, --gradient-hero, --shadow-card, --radius-lg
- Utility-классы: .container, .grid-2, .grid-3, .text-center, .badge
- Анимации: @keyframes fadeInUp, pulse для hero-mockup
- Breakpoints: 1280, 1024, 768, 480

SEO: полный набор meta, JSON-LD SoftwareApplication + Organization + FAQPage.

Язык: русский. Тон: технологичный, уверенный, без воды.
```

## 4. Портфолио дизайнера / разработчика

```
Создай сайт-портфолио для дизайнера или фронтенд-разработчика.

Технологии: HTML + CSS + JS. Zero dependencies. Google Fonts (Space Grotesk + Inter).

Визуальный стиль: тёмная тема по умолчанию (#0a0a0a фон), неоновый accent (#00ff88 или #7c3aed). Минимализм, много воздуха, крупная типографика.

Структура:
1. Header: имя как логотип, переключатель темы (☀/🌙), навигация
2. Hero: «Привет, я [Имя]» — текст с анимацией набора (typewriter эффект на JS), подзаголовок «[Роль] из [Город]», ссылки на GitHub, Telegram, email
3. Секция «Проекты» (главная): CSS grid-masonry (grid-template-rows: masonry или fallback). 6 карточек проектов. Каждая: скриншот (gradient placeholder), название, теги (React, Figma и т.д.), ссылка. Hover: overlay с описанием (opacity transition)
4. Секция «Опыт»: timeline вертикальный (CSS ::before линия + ::after точки). 3–4 позиции: компания, роль, период, краткое описание
5. Секция «Стек»: иконки технологий как pill-бейджи с hover-эффектом, сгруппированные по категориям (Frontend, Design, Tools)
6. Секция «Блог / заметки»: 3 карточки с датой, заголовком и preview-текстом
7. Контакты: форма (имя, email, сообщение) + прямые ссылки (Telegram, email, LinkedIn)
8. Footer минимальный

JS:
- Typewriter-эффект в hero
- Переключатель тёмной/светлой темы (сохранение в localStorage)
- Фильтрация проектов по тегам
- Fade-in при скролле через IntersectionObserver
- Форма: базовая валидация + alert

CSS:
- CSS custom properties для обеих тем (data-theme="light" / "dark")
- Масонри-сетка или fallback на auto-fill grid
- Переходы для смены темы (transition на background, color)
- Кастомный скроллбар (::-webkit-scrollbar)

SEO: meta, og, JSON-LD Person + ProfilePage.

Язык: русский. Весь контент — заполненный (не lorem ipsum), но легко заменяемый.
```

## 5. Лендинг мобильного приложения

```
Создай лендинг для мобильного приложения (финтех / здоровье / таск-менеджер).

Технологии: HTML + CSS + JS. Без зависимостей. Google Fonts.

Дизайн: светлый, с градиентными акцентами. Основной цвет — синий (#2563eb) → фиолетовый (#7c3aed) gradient.

Структура:
1. Header: лого, навигация, кнопка «Скачать»
2. Hero: H1 + подзаголовок, 2 кнопки (App Store + Google Play — стилизованные под реальные бейджи из CSS), mockup телефона по центру (CSS art: прямоугольник со скруглёнными углами, notch, фейковый экран с gradient)
3. Социальное доказательство: «500 000+ скачиваний», рейтинг ★★★★★, лого магазинов
4. Возможности: 3 feature-секции (чередующиеся left-right). Каждая: текст слева + mockup справа (и наоборот). Используй CSS clip-path для декоративных фоновых форм
5. Экраны приложения: горизонтальная галерея из 5 mockup-экранов (CSS-рисованные), scroll-snap
6. Отзывы из магазина: 3 карточки с рейтингом звёздами, текстом, именем
7. Тарифы: Free vs Premium. Сравнительная таблица фич
8. Секция «Безопасность»: иконки + тексты (шифрование, GDPR, 2FA)
9. CTA: «Скачайте сейчас», поле для email (ссылка на скачивание) или QR-код (CSS-generated placeholder)
10. Footer

JS:
- Scroll-анимации для feature-секций (alternate slide-in-left / slide-in-right)
- Счётчик (animateCount): числа плавно наращиваются при попадании в viewport
- Галерея экранов: drag-скролл на мобильных
- Sticky CTA-бар при скролле ниже hero

CSS:
- Декоративные blob-формы через clip-path и pseudo-elements
- Mockup телефона: border-radius: 40px, box-shadow, inner gradient
- Floating animation (@keyframes float: translateY ±10px)
- Адаптив: column-reverse для feature-секций на мобильном

SEO: JSON-LD MobileApplication + AggregateRating.

Язык: русский.
```

## 6. Лендинг онлайн-курса / вебинара

```
Создай конверсионный лендинг для онлайн-курса или вебинара.

Технологии: HTML + CSS + JS. Без фреймворков. Google Fonts (Montserrat + Open Sans или Inter).

Цветовая схема: тёплая — белый фон, оранжевый accent (#f97316), тёмный текст.

Структура:
1. Header с таймером обратного отсчёта (JS): «До старта осталось X дн Y ч Z мин W сек»
2. Hero: крупный заголовок с выгодой (не название курса, а результат), подзаголовок, видео-превью (CSS placeholder с кнопкой ▶), кнопка «Записаться»
3. Проблемы целевой аудитории: 4 карточки «боль» с эмодзи и текстом
4. Программа курса: аккордеон из модулей (5–7 шт), каждый раскрывается с содержанием уроков
5. Спикер: фото-заглушка, имя, регалии, ключевые достижения (цифры), соцсети
6. Результаты: «Что вы получите» — 6 пунктов с галочками
7. Тарифы: 3 пакета (Базовый / Стандарт / Премиум) с чеклистом фич, перечёркнутой старой ценой и текущей
8. Отзывы учеников: карточки с фото, именем, профессией и текстом
9. FAQ: аккордеон
10. Финальный CTA: «Осталось N мест» (отображается число из JS-переменной), форма (имя, email, телефон, select тарифа)
11. Footer: реквизиты, оферта, контакты

JS:
- Countdown timer до заданной даты (обновление каждую секунду, setInterval)
- Аккордеон программы и FAQ
- Имитация ограниченных мест: число из переменной, декремент при каждой отправке формы
- Форма: валидация всех полей, показ модалки «Спасибо» (CSS modal + JS toggle)

CSS:
- Перечёркнутая цена: text-decoration: line-through + color: muted
- Бейдж «Хит» на среднем тарифе: position: absolute, transform: rotate(-3deg)
- Пульсирующая кнопка CTA: @keyframes pulse (box-shadow)
- Countdown: mono-spaced цифры в отдельных box-ах
- Адаптив: 3 breakpoints

SEO: JSON-LD Course + Event + FAQPage. Полный набор og:* мета.

Язык: русский. Тематика: маркетинг / программирование / дизайн (укажи нишу при генерации).
```

## 7. Корпоративный сайт компании

```
Создай многостраничный корпоративный сайт (3 страницы: главная, о компании, контакты).

Технологии: HTML + CSS + JS. Общий styles.css и script.js, подключаемые ко всем страницам. Google Fonts.

Стиль: строгий, корпоративный. Тёмно-синий (#1e3a5f) + белый + светло-серый. Шрифт: Inter или IBM Plex Sans.

Страница 1 — index.html (Главная):
1. Header: логотип, меню (Главная, О компании, Услуги, Контакты), кнопка «Связаться»
2. Hero: полноширинный gradient-баннер, H1, подзаголовок, CTA
3. Услуги: 4 карточки (иконка + заголовок + текст + ссылка «Подробнее»)
4. Цифры: анимированные счётчики (лет на рынке, проектов, сотрудников, клиентов)
5. Партнёры: лого-лента
6. CTA-блок
7. Footer: 4 колонки, соцсети, копирайт

Страница 2 — about.html (О компании):
1. Тот же header/footer
2. Hero: заголовок + breadcrumbs
3. История: timeline (год → событие), 5 записей
4. Команда: сетка из 6 карточек (фото-заглушка, имя, должность)
5. Ценности: 4 блока
6. Сертификаты / награды

Страница 3 — contacts.html (Контакты):
1. Header/footer
2. Карта-заглушка (серый блок с текстом адреса)
3. Форма обратной связи (имя, компания, email, телефон, тема, сообщение textarea)
4. Реквизиты компании: ИНН, ОГРН, юр. адрес
5. Контактные данные: телефон, email, адрес

JS:
- Активная ссылка в меню определяется автоматически по текущему URL
- Анимация счётчиков при скролле
- Мобильное меню (бургер → slide-in)
- Форма: валидация + alert

CSS:
- Единый styles.css для всех страниц
- БЭМ-подобные классы
- Print styles (@media print)
- Плавные переходы между страницами (prefers-reduced-motion учитывается)

SEO: уникальные meta для каждой страницы. JSON-LD Organization + WebSite + BreadcrumbList.

Язык: русский.
```

## 8. Лендинг мероприятия / конференции

```
Создай лендинг для IT-конференции или бизнес-мероприятия.

Технологии: HTML + CSS + JS. Без зависимостей. Google Fonts (Space Grotesk).

Дизайн: тёмный фон (#0f0f23), яркие акценты (gradient: #ff6b6b → #4ecdc4), геометрические фоновые формы (CSS conic-gradient, radial-gradient).

Структура:
1. Header: лого конференции, дата, город, кнопка «Купить билет»
2. Hero: название конференции (крупно, gradient text: background-clip: text), дата + место, обратный отсчёт, CTA
3. О мероприятии: 3 карточки (докладов, участников, треков) + краткое описание
4. Спикеры: сетка 4×2. Карточка: фото-заглушка (gradient circle), имя, компания, тема доклада. Hover: раскрытие bio
5. Программа: табы по дням (День 1 / День 2). Внутри: timeline с временем, спикером, темой
6. Площадка: фото-заглушка, адрес, «Как добраться» (текст)
7. Билеты: 3 типа (Early Bird / Standard / VIP) с ценами и включённым
8. Спонсоры: 3 уровня (Gold, Silver, Bronze) — горизонтальные ряды лого
9. CTA: «Присоединяйся» + форма (имя, email, тип билета)
10. Footer: организатор, контакты, соцсети

JS:
- Countdown до даты мероприятия
- Табы программы (клик переключает день)
- Hover-эффекты на карточках спикеров (раскрытие описания)
- Smooth scroll + мобильное меню

CSS:
- Gradient text через -webkit-background-clip: text
- Glassmorphism на карточках: backdrop-filter: blur(12px), полупрозрачный фон
- Анимация фоновых blob-ов: @keyframes morphBlob
- Сетка спикеров адаптивная: 4 → 2 → 1
```

## Советы по использованию промтов

### Как адаптировать под свой проект

1. **Замени тематику** — каждый промт можно легко адаптировать под любую нишу, изменив тексты, цвета и данные.
2. **Укажи конкретику** — добавь в промт реальные тексты, цены, контакты перед генерацией.
3. **Комбинируй секции** — бери блоки из разных промтов и собирай свой идеальный лендинг.
4. **Итерируй** — после генерации дорабатывай: «Замени цветовую схему на ...», «Добавь секцию ...», «Сделай hero full-screen».

### Чеклист качества сгенерированного сайта

- [ ] HTML проходит валидацию (htmlhint или W3C validator)
- [ ] JS без синтаксических ошибок (node --check)
- [ ] Все ссылки работают
- [ ] Адаптивность на 320px, 768px, 1024px, 1440px
- [ ] Формы имеют валидацию и обратную связь
- [ ] SEO-мета заполнены корректно
- [ ] JSON-LD валиден (проверь через Google Rich Results Test)
- [ ] Шрифты загружаются (или graceful fallback)
- [ ] Нет горизонтального скролла на мобильных
- [ ] Изображения имеют alt-текст
- [ ] Все интерактивные элементы работают (аккордеон, табы, слайдер)
